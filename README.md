# Renewable Energy Monitoring Simulator

## Description
This is a **Python-based simulator** to monitor and analyze renewable energy generation from solar panels and wind turbines.  
It allows you to simulate daily/monthly energy output, generate reports, and visualize trends using plots and an interactive Streamlit dashboard.  
No hardware is required—everything is software-based.

## Features
- Solar energy simulation based on sunlight intensity and panel efficiency
- Wind energy simulation based on wind speed, turbine efficiency, and rotor area
- Generate daily, weekly, and monthly energy reports (CSV)
- Visualize energy trends with Matplotlib plots
- Interactive Streamlit dashboard for visualization and report download
- Easy to modify parameters to test different scenarios
